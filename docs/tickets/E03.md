# E03 — Scoped typed tool registry

Implemented September 20, 2026. See [tool registry](../tool-registry.md) for the
available surface, server-only invocation contract and remaining integration gates.

## Delivered

- Twelve versioned typed tools backed by installed scientific capabilities and
  existing scoped services. Unsupported blueprint tools fail closed.
- Strict argument and ownership checks before effects; trusted run revision,
  claim token, role and current policy checks at dispatch.
- Atomic action/job/link/budget transactions, stable receipts under concurrent
  replay, charged bounded reads and safe failure envelopes.
- Derived scope from committed run outputs with current-policy revocation.
- Schema/aggregate projections, C12 validation-only benchmark reads and immutable
  run-scoped report capture. No arbitrary shell, code, SQL or URL fetch.

## Verification

- Initial Windows Python 3.12 registry/agent/budget regression: **38 passed,
  39 skipped** (PostgreSQL unavailable to that local invocation).
- Expanded Windows registry suite: **16 passed, 16 skipped**, including real
  audit/split/report worker execution and sealed-candidate projection checks.
- Follow-up Windows fault-injection suite: **17 passed, 17 skipped**.
- The first Linux regression was interrupted after existing PDF upload tests
  exposed a transaction leak introduced by the optional-session composition:
  the upload preflight shadowed the supplied-session variable. The preflight now
  uses a separate variable, preserving the standalone submission commit.
- Final Linux Python 3.12 / SQLite and PostgreSQL 16 regression: **220 passed,
  2 skipped** in 172.93 seconds. This includes the final fault-injection and
  mixed-classification tests plus submission, evaluation, agent persistence,
  budgets, provider and public-contract regression suites. The skips are SQLite
  variants of PostgreSQL-specific row-lock/checkpointer checks.
- All **49 schema/OpenAPI files** matched; `pip check` found no broken
  requirements. The existing Starlette deprecation warning remains.
- Python compilation and `git diff --check` passed.

## Handoff

E04/D11 must supply persisted action identities and current scheduler authority.
E10 specialist dispatch, E14 comprehensive context filtering and the unsupported
blueprint tools remain gated. The registry does not enable the coordinator,
perform a model call or establish E02 live account acceptance. No dependency,
public HTTP contract or migration change is required.

Tests used the disposable `sciml-e03-tests` Compose project with source mounted
read-only; its containers, network and test volume were removed after verification.
