# E12 — Agent evaluation discipline

Implemented September 20, 2026. See [agent evaluation](../agent-evaluation.md).

- Centralized selection projections for all agent roles on C12's authoritative
  protocol and exposure services. Explicitly labels predeclared comparison and
  unsupported validation-driven selection/ranking.
- Kept test scalars, predictions and untyped assessments out of selection,
  memory and reuse. The model cannot choose a final-purpose view.
- Added retained per-run final exposure markers and fences against further
  scientific tuning in that run, including compatibility with older C12 records.
- Blocks adaptive resealing for the same dataset after a candidate is accepted
  in the run, even if a provider asks to label it exploratory.
- Re-evaluates current exposure on replayed evaluation reads instead of returning
  stale clean-holdout claims.

**4 expected SQLite skips**. All **49 schema/OpenAPI files** matched and dependency
checks passed. See [shared E09/E12 verification](E09.md#verification) for the
earlier run and final targeted evidence. Tests use synthetic metric canaries and
do not call a live model or claim a scientific performance result.

Final evaluation/reuse/resealing checks passed **30 tests** on Linux with SQLite
and PostgreSQL; schema and dependency checks passed again. Agent execution remains
