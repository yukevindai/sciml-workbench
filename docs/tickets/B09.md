# B09 — Capability and result projections

Status: manual read surfaces implemented September 19, 2026; full agent evaluation-exposure integration remains gated on missing C12/B11. B01/B05/B07/B08/C01 are available in the current tree. See the [read projection contract](../read-projections.md).

## Changed behavior

- Added authenticated capabilities, artifact/job indexes and single-job polling, preserving existing array endpoints and full immutable scientific details.
- Added bounded typed summaries/pages and original external-operation receipt projections. Failed jobs remain failed after receipt reconciliation; unknown and confirmed states remain distinct.
- Added signed project/resource/filter-bound cursors using immutable creation-time/ID keyset ordering. Invalid cursors, unsafe limits and cross-project reads reject.
- Index queries omit heavyweight scientific/request/import payloads. Public job projections omit worker identities, claim tokens, request keys, credentials and raw worker errors; safe error codes remain available on new reads.
- Capabilities advertise only integrated options after checking installed Git pins/public exports. Runtime-readable contracts are distinguished from merely registered future schemas. Missing OCR, chemistry integration, validation-only execution and C12 exposure support are explicit.
- All agent index/detail/download entry points fail closed before content access. No token, input flag or injected callback can authorize test-output release. Manual exposure logging and authorized agent release require C12; this work does not claim to complete that prerequisite.
- Exported six new records (45 schema/OpenAPI files total) and regenerated browser types/validators. No extra migration or UI workflow is introduced.
