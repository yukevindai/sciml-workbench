# D11 — Durable agent scheduler

Scheduler infrastructure implemented with migration `0010`, independent worker
lifecycle, database-time leases, fair advancement, fenced RunService dispatch and
committed PostgresSaver checkpoint pointers. Scientific waits release capacity;
stale lease namespaces cannot replace a committed checkpoint. See the
[runtime contract](../agent-scheduler.md).

HTTP/CLI provider execution stays gated on E04's adaptive coordinator integration.
No model call, application database migration or deployment was performed. Local
SQLite acceptance and PostgreSQL-parametrized tests are included; fresh PostgreSQL
execution is pending where `TEST_DATABASE_URL` is available. Do not treat this as
hosted scheduler or end-to-end agent acceptance.
