# C05 — Evidence ingestion and source bundle

Status: implemented and locally verified September 19, 2026. Prerequisites C01 and D02 are available. Existing uncommitted C01–C04 work was preserved.

## Changed behavior

- The adapter continues to call the pinned public PDF ingestion API and retain its complete record/bundle. A new integrity check verifies original bytes/digest/identity, serialized record equality, page inventory and locators, exact text hashes, text availability and the complete expected file inventory before retaining the ZIP.
- Unreadable PDF/parser or metadata validation failures become safe `VALIDATION_FAILED` job errors with no evidence artifact. Inconsistent output bundles fail as `INTEGRITY_FAILED`. Original attached PDFs remain independently downloadable/reportable after ingestion failure.
- Real text, image-only and mixed fixtures establish per-page inspectability and honest textless-page behavior. Successful image-only ingestion does not imply OCR or successful text extraction. No page mappings, extraction accuracy, measurements or calibration are invented.

The [evidence guide](../evidence-ingestion.md) documents public fields, original/bundle access and limitations. Evidence 1.0/public schemas, dependency pins and database migrations are unchanged. C11 retains ownership of Unicode span references and claim validation; no agent tool or frontend behavior was added.

## Handoff and limits

The raster-only fixture simulates a scan; it is not a broad extraction-quality benchmark. `has_text` only reports text-layer availability. User metadata remains explicitly unverified; current ingestion supplies title only. Original PDFs and extracted text remain untrusted source material, not established scientific claims.

C11 owns supported source references/claims, and later evidence UX/tools own additional presentation/retrieval. OCR and calibrated digitization remain unavailable through workbench. General hostile report archive hardening remains C09 work.

Not rerun: the entire backend suite, Linux/PostgreSQL/Compose startup, browser checks, hosted CI/deployment, restore or live-provider evaluation. No commit, push or deployment was performed.
