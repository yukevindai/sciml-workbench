# E11 — Grounded independent review

Implemented in the trusted backend integration. HTTP/CLI activation uses the
[E04 runtime configuration](../agent-coordinator.md); live-provider acceptance remains pending.

`agent_review.py` checks exact source/metric references before review and derives
the candidate answer directly from its typed claims. The candidate digest binds
statements, classifications, limitations, uncertainty and references. Review
annotations and check timestamps cannot disguise a changed candidate.

The independent provider receives exact verified source spans and permitted
selection metric references. It receives no effect or delegation tools. Backend
reads use C11/C12; test references are removed before provider context is built.
Every claim must receive exactly one verdict for the supplied digest. Unsupported,
conflicting and partially supported claims are omitted from the final narrative.
Residual uncertainty and the original reviewed digest remain explicit.

Review assignments persist their objective, scope, deadline, model allowance and
candidate digest. E05 charges shared allocations and review rounds. The current
policy is one review attempt, with no automatic revision/approval-seeking loop.
Completed review receipts replay without another model call. Interrupted/unknown
review calls are not replayed; finalization omits narrative and produces a factual
partial result while retaining truthful usage reservations.

Acceptance lives in `test_agent_finalization.py`: exact-span review, unsupported
claim removal, changed-candidate rejection, receipt reuse, sealed-test quarantine,
and unavailable-review fallback. Provider responses are deterministic test doubles;
no paid model or empirical live-review quality claim is involved.
