# D05 — Private web/API and stream boundary

Implemented verification and boundary fixes. Production always requires the
operator login, including when `WB_REQUIRE_LOGIN=0`; only development can opt out.
The API handler also applies the operator gate before proxying. Production fails
closed without public origin and a non-placeholder backend token of sufficient
length. Origin-bearing requests and mutations must match the configured origin.

The proxy forwards only approved headers, including SSE `Last-Event-ID`, replaces
browser authorization with the backend bearer token, rejects redirects, propagates
disconnect/timeouts, and returns uncached responses. Cookies and unapproved
forwarding headers are not relayed. Health remains constant and public. Backend
tests cover anonymous access and reconnect attempts across run/project scope.

Validation: actual NextRequest/NextResponse handler tests, TypeScript checks,
production build, and the production Playwright anonymous-access check all passed
locally on September 20, 2026. The live check explicitly used `WB_REQUIRE_LOGIN=0`.
CI runs both boundary tests against pages, API, streams and downloads. Hosted deployment evidence
is outside this local verification and remains D06.
