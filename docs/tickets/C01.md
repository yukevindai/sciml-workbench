Key findings:

- Nine base split strategy names work, including the time/temporal alias. Scaffold and molecular features need the absent optional RDKit dependency and must not be advertised as available in the base installation.

- PDF ingestion preserves original bytes and per-page text/hash/page locators. Image-only pages have no extracted text, and invalid PDFs fail. No OCR or semantic span/digitization capability is implied.

No runtime adapter, dependency pin, HTTP/schema contract or database migration changed. The earlier integration note now accurately describes the shared file lock and unresolved durable reconciliation boundary.
