# E15 — Autonomy and agent evaluation suite

Implemented September 25, 2026. Deterministic local acceptance passes;
live-provider evaluation remains unrun. No paid call or deployment was made.

The [evaluation guide](../autonomy-evaluation.md) describes the versioned fixture,
ledger measurements, safe reports, adversarial/recovery gate and bounded opt-in
live pilot. CI runs the deterministic gate and retains its report on failure.

Two frozen synthetic datasets each run through coordinator-only and specialist
arms. Both complete a real audit without intermediate interventions. Observed
scripted-provider requests are **3 versus 5**, and synthetic token totals are
**60 versus 100**, respectively. This is measured orchestration overhead, not a
live model cost or quality advantage. Monetary cost remains unknown; narrative
claim support is unscored. Real grounding and report checks run separately in
the gate.

The live runner requires explicit opt-in, reviewed runtime configuration/prices,
a per-run ceiling, and a frozen 1–5 attempts per arm. It records model/configuration,
provider nondeterminism, planned and observed samples, failures, resource usage
and latency. It operates only on disposable synthetic fixtures. No configured
provider was needed for local acceptance.
