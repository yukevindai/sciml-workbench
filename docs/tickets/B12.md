# B12 — Agent API and controls

Status: implemented behind unavailable-runtime admission until D11 is operational.

Authenticated project-scoped routes now expose run creation/history/detail, amendments, question answers, exact plan review, pause/resume/cancel, terminal results, ordered event polling and reconnectable SSE. Expected revisions and durable request receipts prevent stale changes and duplicate effects. Original input is immutable; authority only narrows, amendments invalidate old plan acceptance, and generic Resume cannot bypass questions/review. No client route accepts raw checkpoints, leases or tool permissions.

Strict response schemas, OpenAPI and generated TypeScript/browser validators include the new projections. [The service contract](../agent-persistence.md) documents route parameters and semantics. Pause/cancel truthfully fence new dispatch while accepted work may settle; D12 supplies physical drain/cancellation/publication enforcement. New HTTP admission returns `503 AGENT_UNAVAILABLE` until D11, rather than accepting permanently unscheduled work. Tests enable only an injected non-billable admission callback.

Acceptance covers concurrent duplicate creation and controls, conflicting keys, racing distinct controls, stale amendments, terminal transition refusal, exact plan acceptance/replay, post-amendment re-review, attributed answers, authority narrowing/revocation, scope isolation, anonymous stream rejection, SSE sequence replay and strict unknown-field rejection. The final focused backend suite passed **133 tests** with five expected backend-specific skips; [B11](B11.md) records the broader regression and restore evidence.

No user-facing agent workspace, paid provider evaluation or deployment is included; A11/A12 and E04 remain downstream work.
