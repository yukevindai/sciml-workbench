# E14 — Egress and untrusted-content defenses

Implemented September 20, 2026. See [agent egress](../agent-egress.md).

- Centralized credential checks across provider requests/responses, serialized
  tool results and agent HTTP/SSE output.
- Added source-scope checks, inherited classification for derived context and
  explicit untrusted-data records with a fixed system boundary.
- Checked current exposure and complete payload size before budget dispatch;
  rejected tool projections roll back their transaction.
- Removed arbitrary exception text from persisted job diagnostics.
- Added adversarial acceptance tests using synthetic credentials and raw-content
  canaries, with no live provider calls or paid usage.

Agent execution remains disabled pending runtime/coordinator integration.
Scientific source files and archives retain their exact bytes.
