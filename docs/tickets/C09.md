# C09 — Archive verification and scientific replay

Implemented structural verification and comparison-based replay through the existing CLI. Manifest 1.0 is explicitly supported for complete historical reports; new exports use 2.0. Unsafe paths, duplicate members, broken digests/closure/contracts and incompatible scientific environments fail before creating replay output.

Replay uses real public adapters for audits, splits and successful mean/ridge baselines. Assignments and row identity are exact; floating-point diagnostics, predictions, metrics and validation search use rtol=1e-9 and atol=1e-12. Structured comparison records distinguish matched computations, skipped failed benchmarks and replay failure. Failure Memory is not mutated, PDF extraction is verified from retained bytes, and agent text/provider calls are not deterministically replayed.

Validation: real archive/CLI replay, deliberate structural corruption, incompatible pins, missing science, tolerance rejection and configured credential checks are covered. The combined integration run passed **169 tests, 55 skipped**, with final affected slices recorded in C10. Source-pin/constraint/public-surface verification passed. CI installs a fresh constrained Python 3.12 environment; a new CI run and local PostgreSQL acceptance were not executed in this work. See [setup and limitations](../report-replay.md).
