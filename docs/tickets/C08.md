# C08 — Scientific report assembly

Implemented. New frozen captures include software/environment versions and job creation times alongside selected artifacts, materials, evidence anchors, protocol/exposure state and sanitized job fields. Assembly produces deterministic manifest-2 archives and automatically verifies their structure before publication. The publication boundary rechecks archive bytes against the accepted capture.

The shared verifier enforces project/reference closure, source evidence, nested benchmark inventory/hashes/input/partition/prediction correspondence, schemas, safe paths and bounded inventories. Missing/corrupt science and prior report archives cannot pass. Readable reports distinguish actor-aware observations, hypotheses, claim classifications, uncertainty and semantic-review status. Credential field detection and worker-side configured-secret checks reject exports without rewriting scientific evidence.

Validation: the combined C08–C10 real integration/regression run passed **169 tests, 55 skipped** on the constrained Python 3.12 environment. Additional archive/publication regression results are recorded in C10. PostgreSQL was unavailable locally; those skips are not acceptance evidence.
