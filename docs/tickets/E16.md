## Trusted policy installer

`python -m workbench.operator_policy --file <reviewed.json>` validates complete
server/project snapshots and prints their effective intersection. `--file -`
supports stdin in Compose, so private policy files need not enter an image.
The default writes nothing. `--apply` appends both revisions in one transaction;
exact current-pair replay is a no-op. Stop writers and serialize operator changes.

The installer checks referenced projects and input ownership, configured model
scope, reviewed prices for monetary ceilings, and room for one bounded ordinary
model request. Revision conflicts cannot partly install a pair. It does not
automatically grant every upload, merge old server scope, reset budgets, enable
agents, migrate a database or contact a provider. Existing server/project grants
must be reviewed as complete replacement snapshots. No HTTP administrative route
or public schema was added.

The [memory correction recipe](../agent-memory-reuse.md#operator-correction) uses
the existing trusted MemoryService with human attribution, same-kind correction,
the original identity and expected revision. It preserves prior records and keeps
notes out of output. There is no new memory-editing endpoint or table-edit bypass.
